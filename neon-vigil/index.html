NEON VIGIL

Model Viewer

To use a real model, drop a Neon Vigil GLB (for example Val 17 or the Infinity 6) into neon-vigil/models/ and set it as the model's src. For example, add neon-vigil/models/val17.glb or neon-vigil/models/infinity6.glb, then use the Val 17 or Infinity 6 buttons above to load it.
